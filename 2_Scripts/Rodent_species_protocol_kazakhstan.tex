\section{Introduction}\label{introduction}

This document provides a comprehensive analysis of rodent occurrence
data from Kazakhstan using GBIF (Global Biodiversity Information
Facility) records. It is designed to help field teams prepare for rodent
surveillance activities by understanding:

\begin{itemize}
\tightlist
\item
  \textbf{What species} you might encounter
\item
  \textbf{Where} different species have been recorded
\item
  \textbf{When} rodents are most likely to be captured
\item
  \textbf{How reliable} the existing data is
\end{itemize}

\begin{quote}
\textbf{Note}: This analysis is based on opportunistic occurrence
records from GBIF. Patterns may reflect sampling effort and researcher
activity rather than true biological patterns.
\end{quote}
